# Proyecto Web Elisava · Xènia Trallero

Durante siete meses, de abril a octubre, registré mis entrenamientos en Strava. Este proyecto de Diseño Web en Elisava relaciona lo que se ve al abrir una actividad —distancia, ritmo o kudos— con lo que escribí sobre cómo me sentí al correr.

**¿Qué hay detrás de la necesidad de compartir mis resultados en Strava y cómo influye la mirada de los demás en mi manera de mostrarlo?**

## Documentación

- [Contexto](contexto.md) recoge la pregunta, el material de investigación y las cuestiones abiertas.
- [Personalidad](personalidad.md) define la voz del proyecto y su dirección visual.
- [Criterios](criterio.md) explica cómo trabajar con mis registros reales y conservar mis notas íntegras.
- [Registro](log.md) recoge los avances y las decisiones de cada sesión.

## Abrir la web

Descarga el repositorio y abre `index.html` en el navegador. La página carga `style.css` para los estilos y `script.js` para las interacciones.
